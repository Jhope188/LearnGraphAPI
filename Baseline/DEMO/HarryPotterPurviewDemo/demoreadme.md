## Overview

This demo environment contains **20 Harry Potter–themed SharePoint team sites** with **54 documents** across `.docx`, `.xlsx`, and `.pptx` formats. Each site is backed by a Microsoft 365 Unified Group and is ideal for demonstrating Microsoft Purview, Copilot, DLP, sensitivity labels, and SharePoint search/governance scenarios.

## Demo Scenarios

This environment is well-suited for demonstrating:

| Scenario | Example |
|----------|---------|
| **Microsoft Purview DLP** | Flag "CONFIDENTIAL" documents (Veritaserum Brewing Log, Dragon Breeding Research) |
| **Sensitivity Labels** | Auto-label files containing "CONFIDENTIAL" or "KEEP SECRET" |
| **Purview Information Protection** | Classify financial data in Gringotts / Malfoy Manor sites |
| **Copilot for M365** | Search across sites — "Find all documents about dragons" |
| **SharePoint Search** | Cross-site search for terms like "potion", "quidditch", "auror" |
| **Governance & Lifecycle** | Review site ownership, inactive sites, guest access |
| **eDiscovery** | Search for specific keywords across all 54 documents |
| **Compliance Manager** | Audit document access and sharing across groups |

## Re-running the Script

The script is **re-run safe** — it detects existing groups by `mailNickname` and skips creation, then re-uploads documents. To deploy to a different tenant:

```powershell
# Connect to the target tenant and run
Connect-MgGraph -Scopes @('Group.ReadWrite.All','Sites.ReadWrite.All','Files.ReadWrite.All') -NoWelcome
& './Create-HarryPotterDemoEnvironment.ps1'
```

No hardcoded tenant IDs — the script auto-detects everything from the current Graph session.
