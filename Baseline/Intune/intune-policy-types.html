Intune Policy Types: CSP · OMA-URI · Settings Catalog · DDM

Architecture, relationships, deprecations, and recommended approach — June 2026

How They Relate — From Protocol to UI
CSP (Configuration Service Provider)
The Windows OS framework that receives and applies settings from any MDM. Think of it as the engine — all other methods ultimately talk to CSPs under the hood. Not a UI; it's the protocol layer that maps to Registry keys and OS features.
Foundation Layer
OMA-URI (Custom Profile)
A manual escape hatch — you write the CSP path yourself (e.g. ./Device/Vendor/MSFT/Policy/Config/...) when no UI exists for it. Maximum power, maximum risk of misconfiguration. Requires knowing the exact CSP reference.
Use When Necessary
Settings Catalog
A searchable UI wrapper over CSPs (and Apple payloads). Microsoft's current standard and primary investment. Pulls settings directly from Windows CSP docs and Apple DDM/MDM payload keys. Replaces Templates and is the target for all migrations.
✓ Recommended (Primary)
Administrative Templates (ADMX)
Legacy Group Policy ADMX settings surfaced in Intune. Retired for new creation in December 2024 (2412). Existing policies continue to work and can be edited, but you can no longer create new Administrative Template profiles. All settings now exist in the Settings Catalog.
⚠ Retired (Dec 2024)
DDM (Declarative Device Mgmt)
Apple's modern protocol where the device acts autonomously — it declares desired state and self-enforces, even offline. Surfaced in Intune via the Settings Catalog. For Windows, Microsoft's equivalent is "Declared Configuration" (MMP-C/WinDC). Apple MDM software update commands deprecated from OS 26 onward.
✓ Recommended (Apple)

Decision Flow — Which Method Should I Use?
📋 Creating a new Windows policy?
→ Settings Catalog first. Search for the setting. If not found, check the CSP reference and use OMA-URI as a last resort.
🍎 Managing Apple software updates?
→ DDM via Settings Catalog. Legacy MDM update commands are deprecated in OS 26 (2025–2026). Migration deadline before OS 26 ships.
📁 Have existing Administrative Template policies?
→ Keep existing — they still work and can be edited. But rebuild any new policies in Settings Catalog. Admin Templates are retired for new creation since Dec 2024.
⚙️ Need a setting that's not in the Settings Catalog UI?
→ Custom OMA-URI using the exact CSP path from Microsoft's CSP reference docs. Note: Microsoft is restricting OMA-URI to settings genuinely absent from Settings Catalog.
Deprecation & Migration Timeline
Aug 2024 (2408)
macOS Endpoint Protection & System Extensions templates deprecated. Replaced by Settings Catalog equivalents (FileVault, Firewall, Gatekeeper).
Dec 2024 (2412)
Administrative Templates retired for new creation. Cannot create new Admin Template profiles. Existing policies remain functional. Settings Catalog is the replacement path.
Apr 2025
Custom profiles for Android Enterprise personally owned work profile retired. Settings move to Settings Catalog.
Jun 2025 (WWDC)
Apple announces MDM software update commands deprecated in OS 26. iOS 26, iPadOS 26, and macOS 26 will fully remove legacy MDM update commands. DDM required.
Aug 2025 (2508)
Intune adds near-real-time per-device DDM update reporting for Apple. New DDM-based software update report surfaces in admin center.
Late 2026
Apple OS 26 expected general availability. Devices on OS 26+ will ignore MDM update policies if DDM policies are enforced. Complete DDM migration required before this ships.
Key architectural point: CSP, OMA-URI, Settings Catalog, and Templates are all Windows MDM delivery mechanisms that ultimately talk to the same CSPs. They are not competing at the OS level — they are different admin surfaces with different discoverability, reporting, and support trajectories. Settings Catalog is Microsoft's unified long-term surface. DDM is Apple's parallel architectural shift and has a separate (but converging) Windows equivalent in Declared Configuration / MMP-C / WinDC used by Endpoint Privilege Management.
