Section 02

Microsoft Entra Sessions

Source:Ignite 2026 session catalog·Microsoft Security at Ignite 2026

Two themes tie for the largest share of the 37 on-topic Entra sessions: 9 titles name agents and 9 name Zero Trust (some do both). Recovery follows with 6, and passkeys, phishing, or MFA reach only 2. The flagship is BRK343 on Wednesday at 10:15 AM. BRK331 and BRK332 run back to back in the catalog on Thursday at 1:30 PM, the same slot as the Edge breakout BRK397, so pick one. Three pre-recorded sessions (ODSP2103, ODSP2151, ODSP2179) cover identity resilience, recovery, and Entra ID backup. They have no live slot, so they are the ones to queue for the flight.

Section 06

Build and Automate Your Own Session List

Source:Get-EventSession repo·Catalog JSON used here·Ignite 2026 session catalog

The Ignite site is a JavaScript app, so fetching the page returns an empty shell. I skipped it. Michel de Rooij's Get-EventSession script shows where the catalog really lives: a single JSON file. I pulled that file, filtered it with a few regular expressions, and checked the result by hand. Here is the same path, so you can run it for your own products.

1
Find the data source

The repo's script (version 4.49 on master, dated Sept 24, 2026) lists Ignite2026 as a supported event and reads this endpoint. It returned HTTP 200 with 1,444 sessions when I pulled it.

https://eventtools.event.microsoft.com/ignite2026-prod/fallback/session-all-en-us.json
2
Download it and keep one row per session

The file is a flat array. Each entry is one session slot, so a session that repeats appears several times under the same sessionCode. Group by that code and collect the start times. They are UTC, so subtract 8 hours for Pacific in November.

3
Filter by keyword on title and description

The product, solution area and industry tags in the file are empty, so keywords are the only filter. Matching the description as well as the title matters. The repo's -Keyword switch matches titles only, so it would miss description-only hits. This script runs steps 1 to 3 and prints a list. I ran it before putting it here.

import json, re, urllib.request from datetime import datetime, timedelta URL = "https://eventtools.event.microsoft.com/ignite2026-prod/fallback/session-all-en-us.json" PATTERN = re.compile(r"\bentra\b|\bpurview\b|edge for business|microsoft edge", re.I) sessions = json.load(urllib.request.urlopen(URL)) seen = {} for s in sessions: # one row per session code, earliest slot wins text = f"{s['title']} {s.get('description') or ''}" if not PATTERN.search(text): continue start = s.get("startDateTime") row = seen.setdefault(s["sessionCode"], {"title": s["title"], "type": s["sessionType"]["displayValue"], "slots": []}) if start: pt = datetime.strptime(start, "%Y-%m-%dT%H:%M:%SZ") - timedelta(hours=8) # PST in November row["slots"].append(pt.strftime("%a %b %d %I:%M %p")) for code, r in sorted(seen.items()): print(code, "|", r["type"], "|", r["title"], "|", ", ".join(sorted(r["slots"])[:1]) or "on demand") print(len(seen), "sessions")
4
Classify, then check by hand

My own pass split matches into Core (product named in the title, or an identity or data title with the product in the description), Related (on topic by title only) and Mention (description only). It also dropped false Edge hits such as IoT and Azure Local sessions about edge computing. Five sessions (BRK331, BRK336, BRK342, BRK329, BRK335) only surfaced after a manual read, so budget time for that step.

5
Automate the re-run

Save the script, change the pattern to your products, and schedule it to run daily as the event gets close. Compare each run against the last one and look at changed start times and rooms. If you want media or a local cache instead, the repo does that too:

.\Get-EventSession.ps1 -Event Ignite2026 -InfoOnly

It needs PowerShell 5.1 or later, with 7 recommended. I did not run the repo script itself. I read the same JSON directly.

Limit of keyword matching

The first pass finds the sessions that say the product name. It cannot find a good identity session that never uses the word Entra. Treat the output as a shortlist and read it before you build a schedule from it.
